Only chain A protein ATOM records enter each rigid receptor; other chains, waters, ligands, buffers and ions are excluded. Meeko0.8.0 standard residue templates add H and template Gasteiger charges without residue-deletion, flexible-residue or minimization options. Template protonation and the fixed rigid constructs are computational choices, not measured cellular states. Neither receptor is a full-length native membrane protein. Geometry checks use supplied heavy-atom protein PDB; docking uses the matching PDBQT.
