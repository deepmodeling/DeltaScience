# 参考构型

`reference.json` 是原研究公开的优化几何，`reference_metrics.json` 是同一物理口径的计算结果。
`solve.sh` 只用于组织者复算参考分数。此目录不进入选手镜像；做题 Agent 从公开简单起点优化。
`reference_metrics.json` 保留改造前的原始物理指标与连续奖励。2026-11-09 改为基准逐项判定：A≤6 且其余原门槛全部满足才得 1。对该历史指标作评分函数回放，二值结果为 0，其中 A=6.00001199344794。本次没有重跑参考几何的全物理评估；不要将旧连续 reward 当作新版 Oracle 验收结果。
